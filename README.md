# 🎉 Party Time

Aplicação Full Stack para gerenciamento de festas e eventos, desenvolvida com **React**, **Node.js**, **Express** e **MongoDB**.

O sistema permite criar, visualizar, editar e excluir festas, além de cadastrar serviços e associá-los a cada evento, realizando validações de orçamento antes da confirmação.

## ✨ Funcionalidades

- ✅ Cadastro de festas
- ✅ Edição e exclusão de festas
- ✅ Cadastro e gerenciamento de serviços
- ✅ Associação de serviços às festas
- ✅ Validação de orçamento
- ✅ API REST integrada ao frontend
- ✅ Navegação com React Router
- ✅ Notificações utilizando React Toastify

## 🎯 Objetivo

Este projeto foi desenvolvido para consolidar conhecimentos em desenvolvimento Full Stack, aplicando conceitos de CRUD, APIs REST, React Hooks, integração entre frontend e backend, organização em camadas e persistência de dados com MongoDB.
